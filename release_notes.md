# 🛒 Shalimar Store v1.0.0 — Official First Release

**Shalimar Store (Since 1988) — Quality & Purity General Store Mobile Application**

---

### ✨ Features in this Release:
- **Heritage Branding:** High-resolution official circular logo with golden ring, crimson geometric monogram, and custom app launcher icons.
- **Interactive First-Time Walkthrough:** 4-slide onboarding tour welcoming new customers and establishing their shopping profile name.
- **Personalized Header:** Dynamic customer greeting (`Welcome, {username} 👋`) with quick access to saved favorites and past order history.
- **Modern Bottom Deck (Dock):**
  - **Left:** ❤️ Wishlisted / Favorite items with 1-tap re-add.
  - **Middle:** 🏠 Elevated Home Store icon with brand crimson gradient and golden glow.
  - **Right:** 🛍️ Shopping Cart with real-time badge.
- **Floating Cart Deck:** Animated slide-up pill displaying live item count, savings, and total bill.
- **Direct WhatsApp Ordering:** One-tap order dispatch directly to store owner's WhatsApp (`7488151683`) with neatly formatted bill, quantities, prices, and delivery address.
- **Zero-Fee UPI Integration:** Displays store UPI (`7488151683@upi`) with 1-tap Google Pay / PhonePe / Paytm payment link without any payment gateway charges.
- **Owner / Admin Management Portal:**
  - Discreet top-right switch.
  - Fullscreen frosted glass security blur (`BackdropFilter`) demanding Admin ID & Password.
  - 1-tap instant stock availability switch (Green **In Stock** vs Red **Out of Stock**).
  - Add, edit, or delete any inventory item.
  - **1-Click Standard Kirana Catalogue Loader:** Pre-populates 50+ essential Indian grocery items across 9 departments (Atta, Rice, Pulses, Cooking Oils, Spices, Dairy, Biscuits, Cleaning, Personal Care).
  - Admin settings to update login ID and change password.
- **Zero Play Protect / Scan Issues:** Clean Android manifest, modern SDK 35 compliance, and custom release keystore signing.
