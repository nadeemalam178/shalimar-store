### 🌟 What's New in Release v3.2.0

1. **🔐 Compulsory Customer Registration (No Guest Access):**
   - Direct catalog access without authentication has been completely removed.
   - Customers must register or sign in to browse the catalog and place doorstep WhatsApp orders.
   - Session persistence ensures customers stay logged in seamlessly across app restarts.
   - Clean "Sign Out" flow integrated into the customer profile dialog.

2. **⚡ Dual Authentication Providers:**
   - **Name, Email & Password Registration:** Collects Full Name, Email Address, and Password with real-time Firebase profile creation.
   - **Continue with Google:** Instant 1-tap Google Sign-In with automatic name, email, and avatar population.
   - **Password Recovery:** Integrated Firebase Password Reset email dispatch.

3. **☁️ Customer Profiles Collection (`users/{uid}`):**
   - Auto-creates protected customer documents in Cloud Firestore upon registration.
   - Stores `name`, `email`, `phone`, `role`, `provider`, `createdAt`, `lastLoginAt`, and `appVersion`.
   - Protected by comprehensive Firestore Security Rules (`firestore.rules`).

4. **🌓 Complete AMOLED Dark Mode Overhaul for Entry Screens:**
   - **Splash Screen:** Replaced hardcoded white background with pure `#121212` AMOLED canvas with emerald accent glow. Zero white flashes during startup.
   - **Onboarding Carousel:** Replaced white cards and text inputs with dark semantic tokens (`context.surfaceColor`, `context.scaffoldBg`, `context.textPrimary`).
   - **Login Screen:** Built native AMOLED dark mode from scratch with high-contrast inputs and emerald primary buttons.

5. **🛡️ Owner Security Hardening:**
   - Purged all hardcoded admin IDs and plaintext hashes from the client codebase.
   - Admin mode bound to verified owner identity (`AppConstants.ownerEmail`).
