### 🌟 What's New in Release v3.1.0

1. **📲 In-App Direct OTA Updates (No Browser Required):**
   - Download updates directly inside the application with a real-time progress bar (`LinearProgressIndicator`), received/total MB counter, and percentage.
   - Automatically triggers Android's native package installer dialog (`open_filex`) with 1-tap installation.
   - Zero Chrome redirects or external browser downloads.

2. **☁️ Real-Time Google Firebase Cloud Sync (Free Spark Tier):**
   - Powered by **Google Firebase Firestore** (`shalimar-store`).
   - Catalog updates, price modifications, new inventory additions, and stock status changes made by the store owner sync silently to all customer phones in under 1 second.
   - 100% resilient offline-first architecture with instant 0ms cold-start rendering.

3. **🔔 Dual-Tier Push & Local Notification Engine:**
   - **"🔔 Notify Me When in Stock":** Out-of-stock items feature an interactive button allowing customers to subscribe to restock alerts (`restock_<productId>`).
   - **Automated Restock Dispatch:** When the store owner restocks an item in the Admin Panel, a high-priority notification is instantly triggered to subscribed customers.
   - **Local Order Dispatch Alerts:** Native heads-up notifications confirm WhatsApp orders upon dispatch.
   - **Store Broadcast Announcements:** Topic subscription (`store_broadcast`) for seasonal discounts, festive deals, and store timings.

4. **🌓 Complete AMOLED Dark Theme Overhaul:**
   - All customer tabs, navigation bottom docks, floating cart bars, category filters, and search headers refactored with semantic theme extensions.
   - True AMOLED `#121212` background and `#1E1E1E` card surfaces with crisp contrast and readability.

5. **🧹 Production Admin Hardening:**
   - Stripped the demo/test "Quick-Loader" from the Admin Dashboard, ensuring only authentic store products and categories are managed.
